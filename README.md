# Выгоднее

Исходная версия Android-приложения на Flutter. Это стартовый проект, не проверенный APK.
Требования и ограничения: REQUIREMENTS.md.

## Запуск
Установите Flutter stable (Dart >= 3.8), Android Studio/Android SDK и Python 3.
Проверьте `flutter doctor`, примите лицензии `flutter doctor --android-licenses`.
В папке проекта выполните:

```sh
python3 tool/bootstrap.py
flutter analyze
flutter test
flutter run
```

Подключите Android-телефон с отладкой USB либо запустите эмулятор.
После успешной проверки: `flutter build apk --debug`.
APK: build/app/outputs/flutter-apk/app-debug.apk.
Для публикации потребуется собственный applicationId, подпись release и проверки на устройствах.
Версии зависимостей заданы диапазонами; после первого pub get сохраните pubspec.lock.

## Сценарий
Добавьте два товара. Нажатие карточки открывает редактирование.
У самой дешёвой удельной цены зелёный контур. При равенстве выделяются все победители.
Масса, объём и штуки отображаются отдельными группами.
Цена результата переключается над группой. Автовыбор — эвристика, а не классификация ИИ.

Фото вызывает системную камеру. OCR-кандидаты всегда открываются для проверки.
Несколько ценников — эксперимент: отдельный блок OCR может быть только частью ценника.
Отмените лишний блок, дополните цену/количество вручную. Кириллица у текущего OCR не гарантирована.
Цены без явного маркера валюты не подставляются; несколько цен требуют ручного выбора.
Не считайте экспериментальный режим надёжным автоматическим распознаванием российских ценников.
Данные находятся в памяти и сбрасываются при закрытии приложения.

## Будущий iOS
Общая Dart-логика и плагины рассчитаны также на iOS, но проект iOS ещё не создан и не проверен.
На Mac создайте iOS-шаблон Flutter, настройте iOS >= 15.5 по документации ML Kit.
В Info.plist нужны NSCameraUsageDescription и NSPhotoLibraryUsageDescription с описанием назначения.
Сборка требует Xcode и проверки на iPhone.

## Что дальше

3. Реализовать выделение отдельных ценников и сопоставление по координатам, показать области на фото.
4. Добавить восстановление после закрытия камеры системой и локальное сохранение сравнений.

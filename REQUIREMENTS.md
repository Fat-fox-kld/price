# Выгоднее — требования v1

Android первым; Flutter/Dart, общая логика пригодна для будущего iOS.
Без регистрации, сервера и подписок. Валюта первой версии — рубли.

- Любое число товаров, любые названия; сравнение внутри совместимых групп массы, объёма и количества.
- Ручное создание, редактирование и удаление карточек.
- Фото одного ценника, фото нескольких ценников, исправление результатов перед добавлением.
- Одинаковая единица результата для всех карточек группы: 100 г / кг, 100 мл / л, штука.
- Автовыбор по названию, затем медианному размеру упаковок; ручное переключение и возврат к автоматике.
- Зелёный контур у всех минимальных по неокруглённой цене вариантов; одиночная карточка не победитель.
- Только положительные конечные числа; дроби с точкой или запятой.
- Цена означает стоимость всей указанной упаковки. Цена за килограмм на развес вводится как цена и 1 кг.
- Условия скидки, карта лояльности и наборы не интерпретируются автоматически.

## Критерии приёмки
100 ₽ / 80 г → 125 ₽ / 100 г; 120 ₽ / 100 г → 120 ₽ / 100 г; зелёная вторая.
110 ₽ / 0,9 л → 122,22 ₽ / л; 120 ₽ / 1 л → 120 ₽ / л; зелёная вторая.
180 ₽ / 2 кг → 90 ₽ / кг; 240 ₽ / 3 кг → 80 ₽ / кг; зелёная вторая.
Одинаковая удельная цена → зелёные обе. Масса и объём не конкурируют.

## Статус исходной версии
Написаны экран, калькулятор, эвристики единиц, формы и адаптер камеры/OCR.
Тесты подготовлены, но не запускались: в среде нет Flutter/Android SDK.
Нативные каталоги создаются скриптом bootstrap после установки Flutter.
OCR — экспериментальный: ML Kit Latin не заявляет поддержку кириллицы.
Несколько ценников: кандидаты из текстовых блоков, а не готовая сегментация ценников.
Нужны реальные фото, замена/доработка русского OCR и пространственное сопоставление цены с упаковкой.
История и сохранение между запусками пока не реализованы. Перед публикацией также нужны восстановление image_picker lost data, тесты разрешений и жизненного цикла на устройстве.
